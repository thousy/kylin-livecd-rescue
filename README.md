# Kylin-Server-V10-SP3-Desktop-LiveCD

> 银河麒麟高级服务器操作系统 V10 SP3 (x86_64) 企业级运维救援与数据恢复桌面 LiveCD 自动化构建套件。

本项目专为银河麒麟服务器操作系统量身打造，对标商业级运维盘（如统信维护盘、WinPE），可一键复刻并自动封装为包含图形界面的应急救援 LiveCD 镜像。系统完全运行于虚拟内存中，即插即用，具备绝对不破坏物理机原数据的安全特性。

---

## 🌟 核心特性与架构设计

1. **纯净免密图形化桌面**
   - 基于轻量 MATE 桌面深度定制与调优，开机无感秒进桌面，默认自动登录 `root` 用户且免输密码，操作响应迅速。
2. **混合双模引导全兼容 (Hybrid Dual-Boot)**
   - 单一 ISO 镜像原生兼容传统 **Legacy BIOS** 与现代 **UEFI** 启动架构，自适应各类新老服务器、工控机、台式机与主流虚拟化平台（VMware / KVM / VirtualBox）。
3. **分辨率动态自适应与虚拟机性能优化**
   - 开机内置自适应分辨率探测，动态注入 `1920x1080` 显卡模型，根除虚拟化环境下常见的 `800x600` 画面居中与黑边问题。
   - 内置 GTK3 虚拟机优化向导，自动检测虚拟化环境，提供“最佳性能（推荐）”、“均衡”与“最佳视觉”模式一键切换。
4. **启动双模式防二次损坏机制 (2.0.0 增强版)**
   - **系统修复模式**：常规运维场景，支持全盘识别、自动挂载、引导重构与密码清除。
   - **文件恢复模式**：严格禁止自动挂载物理硬盘，底层保持只读保护状态，直接调出专业恢复工具（`testdisk`），防止数据覆盖与二次损坏。
5. **国产系统 LVM / 软 RAID 智能激活**
   - 内置卷组自动激活逻辑（`vgchange -ay`），全自动识别并挂载国产操作系统默认采用的 LVM 逻辑卷与常见软 RAID 分区。
6. **初学者防呆与宿主机安全红线**
   - 彻底移除桌面上危险的“安装到硬盘”图标，防止现场运维误操作导致数据被格盘覆盖。
   - 构建脚本内置 `trap cleanup EXIT` 安全释放机制与多重挂载断言，异常中断时自动恢复制作机现场，杜绝误动宿主根分区。

## 🛠 桌面集成应急运维工具箱

救援桌面直观预置了编号化的应急向导工具，非专业技术人员亦可遵照说明操作：

| 编号 | 工具名称 | 功能描述与适用场景 |
| :--- | :--- | :--- |
| **0** | **应急救援使用说明 (先读我)** | 桌面醒目文字指南，列出各常见故障对应的推荐工具与标准处置流程。 |
| **1** | **一键重置目标系统 root 密码** | 自动扫描物理磁盘与 LVM 分区中的 Linux 系统，仅清除 `shadow` 密码标志位，100% 绝不丢失或改动原系统任何数据。 |
| **2** | **一键修复 GRUB 与 UEFI 引导** | 交互式选择根分区与 boot/efi 分区，一键 `chroot` 重建 GRUB 与 UEFI 引导配置，修复开机卡引导或黑屏。 |
| **3** | **一键自动挂载所有硬盘** | 自动探测全盘 `ext4`、`xfs`、`ntfs`、`fat` 分区并统一只读/读写挂载至 `/mnt/disks/`，自动唤起文件管理器供导出数据。 |
| **4** | **磁盘分区管理 (GParted)** | 图形化磁盘分区编辑器，支持无损调整分区大小、新建分区、格式化与查看文件系统结构。 |
| **5** | **打开原系统桌面** | 智能定位原物理机系统根分区，直接打开管理员或原用户的桌面目录，快速复制导出关键业务桌面文档。 |
| **6** | **文件管理器 (Caja)** | 官方原生文件管理器，便于可视化浏览、跨磁盘复制与挂载外部移动存储设备。 |
| **7** | **一键开启远程协助支持** | 一键启动后台 SSH 服务，生成临时维护密码并在终端高亮显示本机所有 IP 地址，方便外部专家远程连入排查。 |
| **8.1**| **硬盘健康快速诊断 (SMART)** | 物理硬盘 SMART 状态秒测工具，快速研判是否存在硬件致命故障、老化或扇区寿命耗尽。 |
| **8.2**| **硬盘坏道全盘深度扫描 (badblocks)** | 只读安全的地毯式慢扫工具，逐扇区检测物理硬盘是否有物理坏道，并实时统计坏块数量。 |
| **9** | **安全重启电脑** | 自动执行内存写盘强制刷盘缓存（`sync`）后安全重启，避免掉电造成文件系统元数据损坏。 |
| **10**| **安全关机** | 自动同步数据后正常切断电源，保障底层磁盘安全。 |
| **11**| **超级管理终端 (Root Terminal)** | 调起免密的底层 Root 终端，供高级工程师执行深度排查命令。 |

## 🚀 镜像制作与构建操作步骤

### 1. 宿主机环境基线要求

建议在全新或纯净的银河麒麟服务器操作系统（物理机或 VMware/KVM 虚拟机）中执行构建：

| 检查项目 | 最低推荐标准 | 配置说明 |
| :--- | :--- | :--- |
| **操作系统版本** | Kylin Linux Advanced Server V10 SP3 | 架构必须为 **x86_64** |
| **CPU 与内存** | 4 核心 CPU / 8GB 运行内存 | 制作过程涉及多核并发 SquashFS 压缩与虚拟盘同步 |
| **根目录可用空间** | **可用空间 >= 40GB** (建议 80GB+) | 空间不足会导致制作机虚拟盘锁死与构建失败 |
| **网络连接** | 具备互联网访问权限（或配置局域网镜像源） | 需下载 EPEL-Vault 归档源与必备运维组件 |

> [!TIP]
> **宿主机根目录在线扩容提示**：  
> 若宿主机根分区可用空间不足 40GB，且处于虚拟机环境中，可在宿主机扩展虚拟磁盘容量后执行以下命令在线拉伸扩容：
> ```bash
> # 刷新磁盘感知
> echo 1 > /sys/class/block/sda/device/rescan 2>/dev/null || true
> # 自动拉伸底层分区并扩充 LVM
> yum install -y cloud-utils-growpart 2>/dev/null || true
> growpart /dev/sda 2 2>/dev/null || growpart /dev/sda 3 2>/dev/null || true
> pvresize /dev/sda2 2>/dev/null || pvresize /dev/sda3 2>/dev/null || true
> lvextend -r -l +100%FREE /dev/mapper/klas-root
> df -h /
> ```

---

### 2. 配置依赖软件源 (CentOS 8 Vault 归档源)

由于银河麒麟官方基础源未集成 `gparted`，且 CentOS 8 已停止普通维护（EOL），需配置针对 CentOS 8 的 Vault 归档源：

```bash
cat << 'EOF' > /etc/yum.repos.d/epel.repo
[epel]
name=Extra Packages for Enterprise Linux 8 - Vault
baseurl=https://mirrors.aliyun.com/epel-archive/8/Everything/x86_64/
gpgcheck=0
enabled=1
EOF

yum clean all
yum makecache
```

---

### 3. 一键安装构建必备套件

在制作机终端执行以下指令，装齐母盘封装与救援桌面套件：

```bash
yum install -y \
  gparted \
  caja \
  ntfs-3g \
  parted \
  dosfstools \
  xfsprogs \
  e2fsprogs \
  xorriso \
  syslinux \
  dracut \
  squashfs-tools \
  python3-gobject \
  gtk3 \
  testdisk \
  smartmontools
```

**安装验证**：
```bash
which gparted xorriso mksquashfs dracut smartctl
# 预期输出全部为有效的 /usr/bin/ 或 /usr/sbin/ 绝对路径，无 command not found
```

---

### 4. 执行自动化构建脚本

拉取本仓库代码后，直接以 `root` 权限执行构建：

```bash
bash build_safe_desktop_livecd.sh
```

**构建过程说明**：
- 整个构建过程通常耗时约 **3~5 分钟**（取决于 CPU 核心数与磁盘 I/O）。
- 最终产物 ISO 默认保存在：  
  `/root/Kylin-Server-V10-SP3-Desktop-LiveCD.iso`（体积约为 2.3GB 左右）。

---

### 5. 快速导出 ISO 镜像至办公机

如果制作机为无图形界面的远程服务器，可在产物目录下启动临时 HTTP 服务快速下载：

```bash
cd /root && python3 -m http.server 8000
```
在同局域网的 Windows 或 Mac 浏览器打开：`http://[制作机IP]:8000/Kylin-Server-V10-SP3-Desktop-LiveCD.iso` 进行下载，下载完毕后在终端按 `Ctrl + C` 退出。

## 💾 制作实机启动维护 U 盘 (烧录指南)

将生成的 ISO 写入物理 U 盘即可作为实机维护盘使用：

### 方案 A：使用 Ventoy 制作多合一启动盘（强烈推荐）
1. 下载并运行 [Ventoy](https://www.ventoy.net/) 安装程序，选择你的物理 U 盘点击【安装】；
2. 安装完成后，U 盘会显示为一个 exFAT 存储盘，直接将 `Kylin-Server-V10-SP3-Desktop-LiveCD.iso` 拷贝至 U 盘根目录；
3. 将 U 盘插入故障机，开机按快捷键（如 `F11` / `F12`）选择 U 盘启动，在 Ventoy 启动菜单中回车即可直接进入桌面。

### 方案 B：使用 Rufus 写入单一专用维护盘
1. 打开 [Rufus](https://rufus.ie/) 工具，【设备】选择你的 U 盘，【引导类型选择】选取下载好的 ISO 镜像；
2. 分区类型选择 `MBR`（可同时兼容 UEFI 与 BIOS）；
3. **关键步骤**：点击【开始】，在弹出的写入镜像模式提示框中，**务必选择【以 DD 镜像模式写入】**；
4. 等待写入进度完成即可。

## 📋 常见故障应急救援实战指南

当目标服务器无法正常开机时，将维护盘插入机器，在主板开机自检界面按下引导热键（华为/戴尔/联想/浪潮服务器通常为 `F11`、`F12` 或 `F8`），选择 USB 启动进入 LiveCD 桌面：

| 故障场景 | 推荐运行工具 | 标准处置流程与效果 |
| :--- | :--- | :--- |
| **忘记 root 开机密码** | `1. 一键重置目标系统root密码` | 双击打开工具，脚本自动列出包含 `/etc/shadow` 的目标系统分区，输入对应序号按回车即可清空密码。清空后重启，输入 `root` 账户**直接按回车**（空密码）登录。 |
| **开机卡在 GRUB / 引导黑屏** | `2. 一键修复GRUB与UEFI引导` | 交互式输入根分区（如 `/dev/sda2` 或 `/dev/mapper/klas-root`）、`/boot` 分区与 EFI 分区，脚本一键重构并更新 grub.cfg 引导文件。 |
| **系统崩溃急需导出重要数据** | `3. 一键自动挂载所有硬盘`<br>`5. 打开原系统桌面` | 自动扫描并挂载所有物理分区至 `/mnt/disks/` 并弹窗；或使用工具 5 直接定位并打开原系统的用户桌面，插入移动硬盘即可复制关键文件。 |
| **怀疑硬盘出现硬件故障/坏道** | `8.1 硬盘健康快速诊断`<br>`8.2 硬盘坏道全盘深度扫描` | 8.1 针对 SMART 状态秒测是否严重损坏；8.2 对指定磁盘进行只读安全深度扫描，实时显示扇区坏块数量并给出防护建议。 |
| **现场人员无法自行解决故障** | `7. 一键开启远程协助支持` | 双击一键启动后台 SSH 服务，屏幕显示临时维护密码（`123456`）和本机 IP 地址。拍照给后端工程师即可通过终端远程连入排查。 |

## ❓ 常见问题排查与注意事项 (FAQ)

- **Q1：构建过程中提示 mksquashfs 空间不足或 mountpoint 失败？**  
  宿主机根分区可用空间必须大于 35GB。请先通过 `df -h /` 确认容量。若不足请参考前文【宿主机环境基线要求】进行 `lvextend` 在线无损扩容。

- **Q2：在虚拟机下开机发现屏幕右侧或下方有黑边？**  
  系统内置了 1080P 自适应脚本。如果显示器为特殊比例，可在桌面点击开始菜单 ->【系统】->【首选项】->【硬件】->【显示】手动切换分辨率；或在终端执行 `xrandr -s 1920x1080`。

- **Q3：重置密码后，目标机进入系统依然提示密码错误？**  
  请确认在目标机登录界面输入用户名 `root` 后，密码输入框**直接敲击回车（空密码）**，切勿输入任何旧密码或空格。登录后请尽快使用 `passwd` 重新设定安全强口令。

- **Q4：维护完成后如何安全退出？**  
  LiveCD 系统运行于内存中，为确保对目标硬盘的修改与数据写盘安全同步，**切勿直接拔掉服务器物理电源**。请务必双击桌面上的【`9. 安全重启电脑`】或【`10. 安全关机`】退出维护环境。
